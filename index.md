These are web-based tools I use from time to time. Each is a static HTML page
with the logic implemented in the browser; they can be installed as apps and
work offline.

* [NATO Phonetic Alphabet Speller](https://dermoth.github.io/misc-code/webtools/nato.html)
* [RPN Calculator](https://dermoth.github.io/misc-code/webtools/rpn.html)

The source repo is on GitHub: <https://github.com/dermoth/misc-code>

## Installation

Follow these instructions to install these apps as Progressive Web Apps (PWA)
to your mobile's home screen.

Once installed as a PWA you should see a new icon appear on your home screen.
Opening it will open the app as a separate application, like if it came from
the store.

PWA app files are cached locally so they should always work offline. Network
connectivity is only used to pick up new versions of the apps.

### Android

1. Open the app in Chrome - even if you use another browser, Chrome is going
   to be used for PWAs

2. Click on the pop-up notification to install the app, or, if you didn't see
   one, open the menu and choose _Install and create shortcut_

3. If asked between _Install_ and _Create shortcut_, choose the _Install_
   option.

### iOS

1. Open the app in Safari - even if you use another browser, Safari is going
   to be used for PWAs

2. Open the menu and choose _Share_

3. Scroll up the share menu to expose the hidden additional actions

4. Choose _Add to Home Screen_

5. On the _Add to Home Screen_ dialog, ensure the _Open as Web App_ option is
   enabled (it should be on by default) and tap _Add_
